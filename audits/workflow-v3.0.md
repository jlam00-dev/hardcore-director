# 硬核导演3.0候选：范围与发布门槛

设计日期：2026-11-01，联调持续至2026-11-03。基线：v2.2.0固定提交 `ef213d6e90f2f27269fb722753d1dd2caf77e86d`。本文件是开发及验收记录，不是正式发布声明。

## 为什么具备大版本候选资格

此前主要输出创作方案和提示词。新版本加入用户拥有的持久任务状态、真实供应商适配、手机端分镜审核与有额度上限的继续制作：从方法路由扩展到可恢复的生产编排。这个产品边界变化足以作为3.0候选依据，不靠累计组件数量定版本。

## 已确认的产品范围

- 剧本、分镜、执行脚本、图像/视频提示词基于同一项目计划。
- 用户自己的即梦/Design账号、用户自己的飞书/微信；不共享发布者凭据。
- 生图后逐镜审阅，批准内容、上传和视频预算后继续生成。
- 保留驳回、修改、审批失效、服务异常与重启恢复路径。
- 最后只做已确认镜头顺序合成与回传，不声称自主剪辑成熟。
- 不自动发布视频，不自动更改本机系统设置，不自动安装服务，不消费测试额度。

## 发布前必须关闭

1. 本地状态机、累计预算、重复审批、跨用户/跨会话审批与崩溃恢复测试。
2. 账号与项目绑定、实时模型合同、报价和明确的人工批准；绝不以“没有报价接口”推断免费。
3. 两个供应商的真实能力边界。MiniMax Design若无法证明账号身份或安全费用确认，须停在受限/待设置状态，不通过模拟结果掩盖缺口。
4. 飞书和微信的用户自助配置与登录入口；至少一条真实的分镜图片送达→手机审批→视频生成→视频送达链路，经用户验收。
5. 分镜驳回后只重做需要重做的部分；其他已接受素材不被覆盖；变更使旧批准失效。
6. 正式包清单、引用、许可、安全扫描、测试与实际解压复验。
