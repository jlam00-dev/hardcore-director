# v2.1 公开发布门槛

日期：2026-09-05

## 当前结论

v2.1 已可作为隔离验收包测试，但尚不能据此宣称“可公开发布”。代码与清单校验只能证明文件完整、来源追踪可运行，不能替代版权与许可证确认。

## 发布前必须关闭的三项

1. **17 个本机快照的权属未核实**
   - 清单中标记为 `local-authorship-unverified`。
   - 处理方式三选一：确认属于发布者且可再许可；逐项补齐原作者和许可证；改写或从公开包移除。
2. **2 个历史混合模块的来源复杂**
   - `legacy-filmmaking-v1` 与 `seedance-perform-v5-single` 标记为 `historical-provenance-mixed`。
   - 公开发布前应重写为可证明的原创摘要，或只在本机私有包保留。
3. **仓库根许可证尚未选择**
   - 当前没有根 `LICENSE`。
   - 根许可证只能覆盖发布者有权许可的原创部分，不能覆盖或重许可第三方快照。

## 已降低的风险

- `screenwriter` 已重写为 v2.1 原创实现，并移除无许可证上游的嵌套原文副本。
- `story-master` 已重写，移除固定远程 webhook 与不明许可证依赖。
- `short-video-hook-lab` 已重写，避免沿用上游登记许可证与正文许可证冲突的快照。
- Remotion 仅保留路由和边界说明，不复制其规则集。
- MiniMax H3 仅保留原创兼容指南和官方链接，不复制完整官方 Skill。

## 放行条件

只有在上面三项全部关闭，并重新运行包体验证、测试、更新检查和解压复验后，才可创建公开 tag、GitHub Release 或提交 SkillHub。当前操作不得自动推送、发布或覆盖本机现役版本。
