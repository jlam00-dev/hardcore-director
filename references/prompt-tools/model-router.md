# 模型提示词路由器

先判断任务，再选模型。除非用户要求比较，不同时生成三套平台提示词。

## 1. 先锁定输入模式

| 输入/目标 | 路由 |
| --- | --- |
| 纯文字生成音画 | T2V / T2VA |
| 一张起始图继续运动 | I2V / I2VA |
| 首尾帧之间补全过程 | FL2V / FL2VA |
| 多张图、视频、音频分别承担角色、动作、镜头或声音 | Reference / Omni |
| 修改已有视频中的局部内容 | Edit |
| 从已有视频边界继续 | Extend |

## 2. 再按控制需求选模型

- **Seedance 2.5**：30 秒内的完整叙事、多素材参考、长镜头、延长或定向编辑。读取 [seedance-2.5.md](seedance-2.5.md)。
- **Wan 3.0**：需要 Omni 多模态参考、原生长段落、音画联合、首尾帧、参考生视频或视频编辑。读取 [wan-3.0.md](wan-3.0.md)。
- **MiniMax H3**：需要官方固定字段、T2VA/I2VA/FL2VA/L2VA、严格音画时间线或全参考保留分析。读取 [minimax-h3.md](minimax-h3.md)。
- 用户未指定模型且没有决定性差异：先交付一份跨平台导演母版，再给出推荐模型和理由；不要凭空制造三个版本。

## 3. 组合上限

一次任务最多装配：

1. 一个主模块：剧本、分镜、提示词、剪辑或分析之一；
2. 一个模型适配器；
3. 最多两个专项增强：表演、构图、节奏、色彩、声音之中最相关的两个。

如果出现两个不同的主要任务，例如“复杂物理动作 + 精细对白表演”，拆成两个镜头或两次生成，再在后期拼接。

## 4. 统一中间件：导演母版

模型适配前先得到以下事实，不足时只问会改变结果的问题：

- 交付物、平台、画幅、总时长；
- 输入模式与素材清单；
- 主体身份、服装、道具、空间和光线不变量；
- 起始状态、按因果排序的动作、终止状态；
- 镜头构图、机位、运动触发点和停止点；
- 对白、环境声、动作声、音乐或静音；
- 允许改变与禁止改变的内容。

每个参考素材只承担一个主职责，并同时写明不应迁移的属性。参数放在提示词之外，除非平台官方格式明确要求写入时间或字段。

已有多镜头台账时，先按 [分镜机器门禁](../integrations/storyboard-quality-gates.md) 通过本地检查，再从同一份镜头事实生成平台提示词；缺失素材或错误时序先修复。没有实测音频时，对白容量仍是估算。

## 5. 失败后的改单顺序

一次只改一层：素材映射 → 起始状态 → 动作因果 → 镜头 → 表演 → 风格 → 声音。已经成功的层不重写。第二次仍失败时，缩短时长、减少主体或拆镜，而不是继续叠形容词。
