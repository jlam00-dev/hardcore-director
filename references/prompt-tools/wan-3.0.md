# Wan 3.0 提示词工具

用于 Wan 3.0 的文本生视频、图生视频、Omni 多模态参考、首尾帧、参考生视频、视频编辑和长段落任务。

截至 2026-09-04，Wan 官方创作站明确展示了 Omni Reference、原生 30 秒、音画体验、一致性和精准视频编辑，但没有公开一套必须逐字遵循的固定提示词字段。所以下面的字段是本 Skill 的制作模板，不冒充 Wan 官方语法；若界面素材标签不同，以实际界面为准。

官方入口：

- https://create.wan.video/explore

## 任务路由

| 用户目标 | 写法重点 |
| --- | --- |
| 从文字生成 | 把主体、动作、环境、镜头、光影、声音和终止状态写完整 |
| 从一张图生成 | 不重述整张图；写运动、表演、镜头和允许变化项 |
| 首尾帧 | 分别定义首帧与尾帧，中间只写可连续实现的状态路径 |
| 多模态参考 | 每个素材声明角色、保真等级和排除项 |
| 参考生视频 | 把视频拆成动作、镜头、节奏、声音等可迁移属性 |
| 编辑已有视频 | 一个母版、一个编辑范围、一个主要修改、明确保留项 |

## 推荐输出结构

```text
创作目标：[一句话说明目标片段]

素材角色：
@Image1：[定义内容]；保真：[完整保留/部分保留/属性迁移/弱参考]；不要迁移[内容]。
@Video1：[定义动作、镜头或节奏]；不要迁移[人物、服装、场景等]。
@Audio1：[定义音色、对白时序、节拍或环境声]。

起始状态：[人物、物体、空间、天气、光线、机位和已有运动趋势]

时间线：
[0-X 秒]：[可见动作，写清原因、接触、受力、结果]
[X-Y 秒]：[继承上一状态的下一动作]
[Y-Z 秒]：[收束并落到终止状态]

镜头：[景别、机位、主体画面位置、运动触发、路径、速度、停止点]
表演：[目光、呼吸、停顿、肌肉张力、微表情和动作节制]
声音：[对白/音色、环境声、动作声、音乐或静音]
不变量：[身份、服装、道具、数量、方向、产品结构、场景地理]
终止状态：[最终人物位置、道具状态、构图、光线和残余运动]
排除项：[只列会使本镜报废的高概率错误]
```

生成参数另列，不要混进正文：`时长 / 画幅 / 清晰度 / 输入模式 / 素材顺序`。

## Omni 素材契约

- **图像**优先承担身份、产品结构、服装、场景或关键帧；
- **视频**优先承担动作、表演、运镜、物理过程或剪辑节奏；
- **音频**优先承担声音身份、台词时序、音乐节拍或环境声；
- 同一属性只能有一个主素材，其他素材只能补充，不能竞争；
- “属性迁移”必须点名目标，例如“把 @Image3 的织物纹理迁移到角色 A 的外套”，不能只写“参考材质”。

## 首尾帧路径

```text
@Image1 定义首帧：锁定[构图、主体位置、姿势、道具、场景和镜头方向]。
@Image2 定义尾帧：锁定[最终构图、姿势、道具状态、场景和镜头方向]。
从首帧开始，[连续的中间动作和构图变化]，逐步缩小与尾帧的差异，并在最后稳定落到 @Image2。不要瞬移、重置身份、改变道具数量或绕过中间物理过程。
```

## 编辑模板

```text
以 @Video1 为唯一编辑母版。完整保留其时长结构、镜头运动、主体身份、动作时序、未编辑区域、光线和声音关系。仅在[时间/空间范围]把[目标对象]改为[新状态]；新对象必须继承旧对象的路径、速度、遮挡、接触和离场时机。其他内容不变。
```

## 质量门禁

- 不把官方未公开的字段、限制或参数写成确定事实；
- 时间段覆盖完整时长且按因果衔接；
- 多人分别写站位、朝向、动作和说话归属；
- 镜头只有一个主要运动逻辑；
- 动作有受力、过程与落点，布料、液体、头发和粒子有收束状态；
- 产品文字、标志和界面文字若必须准确，使用参考素材并预留后期复核，不承诺逐帧文字无误。
