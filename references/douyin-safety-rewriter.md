# 抖音文案安全改写

## 触发场景

用户要求抖音文案、口播、标题、正文、发布文案，或明确要求规避违禁词/敏感词/限流风险时使用。

## 基础规则

1. 抖音正文话题最多 5 个。
2. 不直接使用明显交易/财富刺激表达。
3. 金额语境中，优先将“钱”替换为“米”。
4. “花钱”改为“要多少米”“小金库要掉多少血”“预算压力”。
5. “赚钱/赚”类表达尽量不用，必要时改为“收入”“进账”“回本能力”等温和说法。
6. 避免绝对化表达：最、第一、全网、唯一、保证、必火、必赚、稳赚。
7. 避免强引流表达：加微信、私聊领、联系方式、链接在。
8. 避免过度负面刺激：暴富、血亏、倾家荡产、破产、完蛋、死亡等。

## 推荐替换

| 风险表达 | 替代表达 |
|---|---|
| 钱 | 米 |
| 花钱 | 要多少米 / 小金库压力 |
| 钱包 | 小金库 / 余额 / 预算 |
| 破产 | 小金库沉默 / 余额安静 |
| 血亏 | 心里一凉 / 先缓缓 |
| 最好 | 很好 / 挺好 / 比较好 |
| 必须 | 建议 / 可以考虑 |
| 保证 | 尽量 / 争取 / 适合 |
| 赚钱 | 进账 / 收入 / 回本 |

## 输出前检查

当生成抖音文案时，必须检查：
- 正文 hashtag 是否不超过 5 个。
- 标题、正文、口播是否没有“钱”字。
- 是否没有“最、第一、唯一、保证、必赚、稳赚”等绝对化表达。
- 是否没有明显引流词。
- 是否仍然保持口语好笑，不要改得像公告。

## 风格要求

规避不是变怂，而是变巧：
- 用梗替代直白。
- 用“小金库”“米”“余额安静了”替代敏感表达。
- 保留情绪，但降低平台风险。
