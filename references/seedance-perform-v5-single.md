==========================================================

【本版说明】
本版为单段产出版，只做：对给定的单个场景/单段，产出一条完整的最终提示词。
不做：装箱、分段规划、段首段尾强制设计、拼接差异规划、分镜板交付等任何分段拼接工程。

【目标】
将给定的单个场景描述、剧本片段或分镜构想，转化为可直接投喂 Seedance 的高质量视频生成提示词。
以提示词工程规范为宪法层，全程生效；动作导演构思与表演指导作为可选模块，按场景类型启用。
产出标准：画面信息完整、风格锁定、素材锚定明确、运镜与节奏可执行、人物情绪可读可演。

----------------------------------------------------------
【适用范围】
- 面向单个场景/单段，产出一条完整提示词。
- "导演构思模块"为可选层：战斗、追逐、强动作、强节奏场景启用；日常对话、文戏、静态氛围、空镜等非动作场景可跳过，直接进入提示词落地层。
- "人物表演模块"为可选层：凡画面中有人物且情绪、关系、心理是表达重点的场景启用，包括对话、文戏、情绪特写、人物反应、表情包式镜头等；纯空镜、纯产品展示、无人物场景可跳过。
- 动作场景可同时启用导演构思层与人物表演层，前者管动作物理与运镜，后者管人物情绪与微表情。
- 不负责把长剧本切分或做分段拼接，只处理给定的单个场景/单段。

----------------------------------------------------------
【总规则】
1. 单段视频时长建议硬上限 15 秒；每段顶部必须写"视频时长:{X 秒}"。
2. 每段必须包含 风格锁定、素材锚定、画面落地正文。
3. 最终提示词必须是全正向画面描述，只写画面里有什么、正在发生什么、声音如何贴合动作。
4. 全程使用中文专业术语，运镜/声音/光学/质感一律用规范中文术语，如 变速升格、滑动变焦、手持拍摄、画外音、剧烈咳嗽声、门吱呀声 等。
5. 术语与叙述不做同义重复，一个信息只写一次。
6. 段内多镜使用 硬切 分隔（这是单段内部的镜头切换，不是分段）；正文中每个镜头另起一行，行首标注「镜头N Xs:」（X 为整数秒），各镜时长相加等于总时长。
7. 构思层允许使用时间戳，最终提示词中全部转写为自然语言节奏词，如蓄力时、命中的一瞬、落点刹那、随即、久久不散等。
8. 人物用 @中文名 锚定、道具用 @道具名 锚定；正文去掉 @，其余名称与锚定块完全一致；场景单独一行以「本片段场景设定在：」开头。
9. 人物情绪一律转化为可见表演，禁止只写抽象情绪标签，必须落到眼神、微表情、肌肉张力、身体语言上。
10. 微表情优先于大动作；除非情节要求强烈爆发，默认使用克制、真实的微表情表达。

----------------------------------------------------------
【模块零:执行总流程速查】
1. 判断当前段的场景类型 → 决定启用哪些可选模块。
   - 有动作物理调度 → 启用模块一（导演构思层）。
   - 有人物且情绪重要 → 启用模块一点五（人物表演设计层）。
2. 内部完成构思与表演拆解（草稿，可含时间戳与情绪分层）。
3. 按 风格锁定 → 素材锚定 → 连续叙述正文 输出该段最终提示词。
4. 交付前执行自检清单。
5. 一个纯文本代码块交付，末尾附 ID 替换与人工复核提醒。

----------------------------------------------------------
【模块一:导演构思层】(可选 - 动作场景)
仅在动作、追逐、战斗、强节奏、强身体调度场景启用。
此层用于理清动作逻辑、节奏、物理反馈与运镜策略。
导演构思层可以作为内部草稿，不直接复制进最终提示词；最终必须转写为自然语言画面描述。

1. 时间轴切分
- 按片段实际时长与内容，择优确定打点数量与位置。
- 不强制拆成固定数量的动作区间，按动作密度和情绪变化安排。
- 打点时刻可使用精确时间戳作为构思草稿，例如 0.0s / 1.2s / 3.8s，用于理清节奏。
- 最终提示词中不出现时间戳。

2. 打点设计
- 每个关键打点明确三件事：此刻发生什么动作、镜头在做什么、物理反馈是什么。
- 动作要有起势、爆发、命中、反馈、收束。
- 人物身体调度要清楚，包括重心、方向、距离、姿态变化、受力结果。

3. 物理反馈择优
- 按动作性质选择反馈，不堆叠无关效果。
- 拳脚打击可用肌肉震颤、衣料抽动、短促冲击声、轻微震屏。
- 重击落地可用尘爆、地面碎裂、低频余震、镜头震动。
- 金属碰撞可用火星、尖锐撞击声、短促反光。
- 高速闪避可用 运动模糊、快速横摇、风压、衣摆拖影。
- 能量类攻击可用气浪、光晕扭曲、空气折射、低频轰鸣。
- 情绪压迫类动作可减少特效，强调呼吸、眼神、停顿与慢推镜头。

4. 运镜设计
- 为每个关键动作匹配运镜手法，使镜头服务动作力度与情绪。
- 爆发动作可使用 变速升格、快速横摇、手持拍摄、镜头震动。
- 压迫感可使用 缓慢推近、滑动变焦、锁定机位。
- 闪避与追逐可使用 跟踪拍摄、甩镜、低角度跟拍。
- 命中瞬间可使用 变速升格、冲击震屏、微升格。
- 情绪收束可使用 固定定格、缓慢拉远、浅焦。

5. 声音设计
- 声音必须贴着画面发生，不孤立堆叠。
- 贴身声包括呼吸、衣料摩擦、脚步、骨节发力、兵器划风。
- 环境声包括风声、雨声、电流、远处人群、机械低鸣、空间回响。
- 动作反馈声包括 打击声、金属撞击声、地面轰隆声、碎屑坠落声、剧烈咳嗽声 等。
- 配乐只写基调，不写具体曲名。

----------------------------------------------------------
【模块一点五:人物表演设计层】(可选 - 有人物且情绪重要的场景)
本模块提供一套表演指导系统，用于把人物内心情绪转化为可见、可演、可拍、可生成的表演结构。
凡画面中有人物且情绪、关系、心理是表达重点时启用，包括对话、文戏、情绪特写、人物反应镜头等。
此层作为内部构思草稿，理清人物情绪逻辑后，转写进最终提示词的画面落地正文，不单独成段。

核心原则：
- 情绪必须可读，动作必须服务情绪，微表情优先于大动作。
- 禁止只写"开心、难过、生气、震惊"等抽象情绪词，必须转化为可见表演。
- 输出必须可表演、可拍摄、可生成、可检查。

1. 情绪分层拆解
每个有情绪的人物，先拆四级情绪结构：
- 表层情绪：观众第一眼看到的反应（开心/生气/委屈/震惊/害羞/冷淡/认真等）。
- 次级情绪：藏在表层下面的动机（不服/想被关注/怕被拒绝/想靠近/想隐藏脆弱等）。
- 对抗情绪：内部或外部的冲突来源（羞耻/防御/自尊受伤/不想服软/不敢承认等）。
- 核心情绪：人物更深层的人格底色（依恋/孤独/骄傲/脆弱/倔强/渴望被看见等）。

拆解公式：
人物当前表演 = 表层情绪 + 次级情绪 + 对抗情绪 + 核心情绪
示例：小生气 = 表层生气 + 次级委屈 + 对抗是不想服软 + 核心是希望被在乎。

2. 微表情设计（眼神优先）
- 眼神方向：直视(坚定/对抗)、回避(羞涩/心虚)、偷看(喜欢/不确定)、下压(克制怒意)、放空(失神)、上看(请求/期待)、侧看(防御/观察)。
- 眼神强度：松(温柔)、稳(专注)、紧(警觉)、锁定(愤怒/决心)、闪动(犹豫/心虚)。
- 眼皮张力：放松(温柔)、上眼皮微抬(惊讶)、下眼睑轻收(压住情绪)、半垂(冷淡)、张开过大(震惊)。
- 瞳孔状态：放大(震惊/喜欢)、收紧(防御/警觉)、失焦(失落)、聚焦(决心)。
- 眉部：眉头轻收(认真/不满)、眉尾下压(委屈/失落)、眉毛上抬(惊讶/请求)、单侧眉轻动(怀疑/挑衅)、眉间紧绷(压抑/生气)。
- 嘴角：轻微上扬(开心)、压住(忍笑/克制)、下压(委屈/假生气)、僵住(尴尬/心虚)、单侧轻动(轻蔑/调皮)。
- 嘴唇：放松(亲近)、轻抿(认真/小生气)、紧绷(压抑/愤怒)、微张(震惊/欲言又止)、张开又闭上(想说但忍住)、下唇轻收(委屈/不服)。
- 下颌：放松(温柔)、轻收(克制/低落)、绷紧(忍耐/自尊受伤)、微抬(骄傲/装镇定)、微缩(害羞/防御)。

3. 面部张力三档
- 0% 张力：完全放松，适合软萌、温柔、亲近、日常。
- 50% 张力：情绪表达清晰，适合认真、小生气、期待、请求、轻微委屈。
- 100% 张力：冲突爆发，适合震惊、愤怒、崩溃、强烈恐惧。
默认建议：除非情节明确要求强烈爆发，否则优先使用 30% 到 60% 的面部张力。

4. 身体语言与肌肉控制
- 手指：自然放松(亲近)、合拢(撒娇/请求)、指向对方(质问)、抓紧衣角(紧张)、悬停(犹豫)、轻敲(焦虑)。
- 手掌：开放(信任)、收缩(防御)、贴近身体(害羞)、朝外(拒绝)、双手靠脸侧(撒娇/惊讶)、交叠(克制/紧张)。
- 肩颈：肩膀放松(安全)、微缩(委屈)、抬起(紧张/防御)、下沉(失落/放弃)、颈前伸(靠近/好奇)、颈后撤(拒绝/惊讶)。
- 身体轴线：前倾(亲近/认真倾听)、后仰(拒绝/震惊)、侧开(保留/躲避)、转向对方(在乎)、身体不转但眼神转(嘴硬/想看又不承认)、偏头(疑惑)、低头(失落/回避)、抬头(逞强/不服)。
- 下肢：稳定站姿(冷静)、膝盖微内扣(羞涩)、脚尖朝对方(在意)、脚尖偏离(想走)、脚步停住(犹豫)、轻轻后撤(退缩)。

5. 呼吸感（表演真实感来源，同时是声音设计的贴身声）
- 呼吸放松(安全/日常)、变浅(紧张/克制)、吸气停住(震惊/被击中)、轻轻呼气(释然/放下)、急促(慌张/情绪上升)。

6. 景别与表演匹配
- 特写：拍眼神变化、微表情、嘴角控制、下颌绷紧、泪光将落、爆发前一秒。表演要小，微表情要准。
- 近景：拍情绪清晰表达、轻微手部动作、肩颈变化、对话反应。脸部+肩颈+手部小动作。
- 半身：拍情绪+手势、人物与道具互动、防御或靠近。面部+手势+身体轴线+肩颈。
- 全身：拍人物关系、空间距离、退缩与靠近、站姿。靠身体方向、脚尖、距离、重心表演。
- 背影：拍情绪收束、离开感、关系断开、孤独感。靠肩膀、头部角度、停顿、步伐速度表演。

7. 光线与表演情绪
- 柔光(温柔/亲近)、侧光(克制/复杂/情绪张力)、背光(离开/孤独/轮廓感)、低光(压抑/隐藏/防御)、明亮均匀光(轻松/日常/商业感)。

8. 表演转写规则（从构思草稿到最终正文）
- 内部可用"主情绪/副情绪/眼神/眉部/嘴部/下颌/张力/呼吸/身体"分点拆解。
- 转写进最终提示词时，串成连续自然语言，嵌入画面落地正文的人物描述中，不保留分点格式。
- 反例（禁止）：她露出复杂的眼神。
- 正例：她先看向对方的手，停半秒，再抬眼看向对方眼睛，眉尾轻轻压下，嘴唇动了一下但没有开口。

【模块二:风格锁定层】
每段提示词顶部必写，固定顺序输出以下字段：

视频时长:{X 秒}
胶片/质感基调:{颗粒、审美流派、材质感、色调倾向}
画幅 + 整体基调 + 本段情绪走向:{画幅比例、视觉气质、情绪变化}
光线规范:{光源方向、光源性质、阴影形态、空气介质}
景深规范:{f 值、焦点策略、前后景虚化关系}
环境声基调:{底噪、贴身声、空间声、有无配乐}

【战斗类场景默认光学规范】
战斗、追逐、强动作场景默认使用：
- 宽银幕画幅 2.35:1 或 2.39:1。
- f/1.4–1.8 浅景深。
- 高频动作中允许 运动模糊、变速升格、镜头震动，但要服务动作，不喧宾夺主。
- 光线强调方向性、体积感和空气介质，使拳脚、兵器、尘埃、火星或气浪有明确层次。

【非战斗场景光学建议】
- 常规对话可使用 f/1.8–2.8，稳定构图，突出表情与眼神。
- 极端情绪特写可使用 f/1.4，压缩背景，强化呼吸、泪光、皮肤纹理。
- 空镜与环境叙事可使用 f/2.8–5.6，保留空间层次与环境信息。
- 产品、道具、细节镜头可按主体材质选择 微距镜头、浅焦、镜面高光 等术语锚定。

【表演类场景光学建议】
- 情绪特写优先用 f/1.4–1.8 浅景深，把焦点锁在眼神与微表情上，背景柔化成散景。
- 对话双人场景可用 f/2.0–2.8，保留两人面部清晰度，便于呈现眼神交流与反应。
- 表演光线按情绪选择：柔光配温柔亲近，侧光配克制复杂，背光配离别孤独，低光配压抑防御。
- 强情绪场景的光线规范字段应写明光如何落在面部，例如"侧光压低半边脸，眼窝留暗，泪光处有高光点"。

----------------------------------------------------------
【模块三:素材锚定层】
风格锁定 之后必写，顺序为：场景设定行 → 人物锚定 → 道具锚定。

0. 场景设定行
- 风格锁定之后、人物锚定之前，单独一行写场景，格式固定为：本片段场景设定在：{场景名}。
- 场景名简明可辨，如 雪夜林道、大内城外的露天舞台、废弃厂房。
- 该行之后如需补充场景的空间结构、陈设、材质、天气、空气介质等，可紧接其后描述，或在镜头正文首句交代。

1. 人物锚定
- 每个出现的人物在锚定块用 @中文名 形式锚定；有名字用名字，无名字用身份词，如 @沈砚、@主角、@刺客、@老者。
- 格式：@中文名 后紧接外观与表演基调描述，例如「@沈砚 玄色劲装外披旧斗篷，束发，眼神沉冷，表演基调克制警觉」。
- 人物锚定需说明外观核心特征，包括服装、发型、体态、年龄感、气质、伤痕或特殊标记。
- 有表演的人物附带"表演基调"，例如气质克制、眼神锋利、习惯性抿唇等，使表演风格统一。

2. 道具锚定
- 关键道具在锚定块用 @道具名 形式锚定，例如 @锈剑、@信物玉佩。
- 格式：@道具名 后紧接外观/材质/状态描述。
- 战斗武器、信物、文件、车辆、产品、特殊装置等必须单独锚定。
- 道具状态需在锚定或镜头正文中交代清楚，例如破损、沾血、发光、熄灭、遗落、被握住等。

3. @ 只出现在锚定块，正文一律用纯名字（关键规则）
- @ 符号仅用于风格锁定之后的人物/道具锚定块，用来定义角色与道具。
- 进入镜头正文后，一律使用纯中文名字，不带 @，例如锚定写「@萧决」，正文写「萧决」；锚定写「@断雪刀」，正文写「断雪刀」。
- 正文中的名字与锚定块中 @ 后的名字必须完全一致，仅差一个 @ 符号，靠一致命名与风格锁定描述保持视觉统一。
- @中文名 为可直接使用的引用名，无需替换占位符；若对接平台素材库，将锚定块中的 @中文名 对应到库中该角色/道具素材即可。

【模块四:画面落地层】
风格锁定 与素材锚定之后写正文描述。

1. 全正向描述
- 只写画面中出现的内容、人物正在做的动作、环境正在发生的变化。
- 最终提示词避免使用否定式指令。
- 用正向构图描述替代限制性描述，例如"人物位于画面左三分之一处，右侧留出昏暗走廊纵深"。

2. 中文专业术语锚定
- 用连续中文叙述画面、动作、情绪、空间关系。
- 运镜、声音、光学等一律使用规范中文专业术语。
- 专业术语嵌入对应动作或声音位置。
- 术语与叙述不做同义重复。

3. 连续叙述 + 分镜头标注
- 正文按镜头分行：每个镜头独占一行，行首标注 镜头号 + 时长，格式为「镜头N Xs:」，其中 N 从 1 开始递增，X 为该镜头时长的整数秒（只精确到秒，不出现小数）。
- 标签之后的镜头内容照旧写法：一镜内用连续自然语言串联人物、动作、运镜、物理反馈、声音，不使用列表式分点，构思层时间戳转为自然语言节奏词。
- 镜头之间仍使用 硬切 分隔；写法上表现为上一镜行末的 硬切 之后换行、下一行以「镜头N Xs:」开头，硬切 与镜头内描述、专业术语的写法均不改变。
- 各镜头时长相加应等于顶部「视频时长」字段的总秒数。
- 单镜（整段只有一个镜头）时，正文仍以「镜头1 Xs:」开头单独成行。

4. 空间锚定与站位朝向规范（防止模型把人物站位/朝向弄反的关键）
问题根源：只写「画面左/右」时，模型不知道相机从哪个方向看、人物脸朝哪，会自行脑补导致朝向错乱。解决办法是每镜同时锁定「软机位 + 站位 + 朝向 + 动作方向」四件套。
- 画面左右保留（构图语言）：「画面左侧/右侧/左三分之一」等是构图信息，决定视觉重量与视线引导，必须保留，不可删除或回避。
- 软机位先行：每个镜头首句给一个「软机位」——用 景别 + 角度 + 视角关系 定相机，例如「低角度侧向机位横向拍两人对峙」「平视越肩机位从沈砚右后方切到正面近景」「低角度跟拍机位横向展开动作」「中景侧向机位框住两人交锋」。软机位只定角度与视角关系，不写死具体距离坐标（如"架在右后方三米"），给模型留出生成空间。
- 朝向必写、与站位分开：人物「站在哪」（画面左右/前后景）与「脸朝哪」是两条独立信息，都要写。朝向用「身体半侧、面朝画面右方」「正面朝向沈砚」「背部半侧对镜头」等描述，对峙关系用一句朝向钉死。
- 动作带方向：动作要写明在画面中的方向，并与左右构图咬合，例如「敌方自画面右侧向左突进」「钢管由右向左横扫」「沈砚向左侧身闪避、顺势朝右一步踏进内圈」。
- 纵深辅助：需要时用「近景/远景、前景/后景」补充纵深关系（如"敌方站在其身后远处的火光前"），与左右一起把二维构图和三维空间同时锁住。

5. 声音随画面嵌入
- 声音要贴合动作、物体、环境变化出现。
- 人声、喘息、脚步、碰撞、风声、门响、金属声、环境底噪等写在对应画面之后。
- 声音术语可用 画外音、门吱呀声、金属撞击声、打击声、地面轰隆声、剧烈咳嗽声、衣料摩擦声 等。

6. 人物表演随画面嵌入
- 有人物且情绪重要时，把模块一点五拆出的表演转写为连续画面描述，嵌入对应人物的动作处。
- 情绪不写抽象标签，落到眼神、眉部、嘴部、下颌、面部张力、呼吸、手部、身体轴线上。
- 表演描述要与景别匹配：特写写眼神与微表情，半身写手势与肩颈，全身写身体方向与距离，背影写肩膀与停顿。
- 表演与运镜、声音协同出现，例如"她抬眼直视镜头方向，眉尾轻压，呼吸明显变浅，镜头 缓慢推近 压近她的脸，环境声只剩低频底噪"。

7. 画面信息完整
- 每段首句交代地点、主体和稳定状态。
- 画面中重要人物、道具、空间位置、光线方向、动作关系必须清楚。
- 战斗和追逐场景要写清楚双方距离、方向、速度、受力结果和落点。
- 文戏和对话场景要写清楚人物站位、眼神、表情、停顿、手部动作和环境声。
- 空镜要写清楚空间层次、光线变化、空气介质、环境动态和情绪指向。

【模块五:写法铁律】
1. 风格服从内容，信息完整优先，不为简短牺牲关键画面信息。
2. 最终提示词全程正向描述。
3. 中文叙述画面与情绪，专业术语用规范中文，术语与叙述功能区分明确。
4. 连续叙述，不使用条列式正文。
5. 时间戳只用于导演构思层，最终提示词全部转为自然语言节奏。
6. 物理反馈择优叠加，精准对应动作性质。
7. 每段顶部必带"视频时长"字段，单段时长建议硬上限 15 秒。
8. 人物用 @中文名、道具用 @道具名 锚定；正文去掉 @，其余名称与锚定块一致；场景单独一行以「本片段场景设定在：」开头，置于锚定之前。
9. 段内镜头切换使用 硬切（单段内部多镜，非分段）；每个镜头另起一行，行首标注「镜头N Xs:」，各镜时长（整数秒）相加等于总时长。
10. 转场效果属于剪辑端操作，提示词端只写画面内容。
11. 画面左右等构图信息必须保留；每镜以「软机位（景别+角度+视角关系，不写死距离坐标）+ 站位 + 朝向 + 动作方向」四件套锁定空间，人物「站在哪」与「脸朝哪」分开写，动作写明画面方向并与左右构图咬合，防止模型把站位或朝向弄反。
12. 最终交付时，每段提示词一个纯文本代码块，可直接复制使用。
13. 人物情绪必须转化为可见表演，禁止只写"开心""生气""震惊"等抽象情绪词，必须落到眼神、微表情、肌肉张力、身体语言。
14. 微表情优先于大动作，除非情节明确要求强烈爆发，默认 30%-60% 面部张力，避免夸张瞪眼、咧嘴、大哭。
15. 表演必须与景别匹配，与人物处境一致，不让所有人物使用同一种表情模板。
16. 呼吸感既是表演真实感来源，也是贴身声的一部分，情绪重的镜头应写明呼吸状态。

【模块六:交付流程】
根据用户需求执行三阶段。用户只要最终提示词时，可以内部完成阶段一与阶段二，只输出阶段三成品。

阶段一 — 导演构思 + 表演拆解（内部草稿）
- 动作、追逐、战斗、强节奏、复杂调度场景启用导演构思（时间轴打点、关键动作、运镜、物理反馈、声音钩子）。
- 有人物且情绪重要的场景启用表演拆解（情绪分层、眼神/微表情/张力/呼吸/身体语言、景别匹配）。
- 此阶段为内部草稿，最终提示词中不出现时间戳和分点格式。
- 纯空镜、纯产品、无人物且无动作场景可跳过本阶段。

阶段二 — 提示词落地
- 按"风格锁定 → 素材锚定 → 分镜头正文"顺序写成该段最终提示词。
- 构思层时间戳全部转为自然语言节奏词；表演拆解转为连续画面描述嵌入正文。
- 正文按镜头分行，每行以「镜头N Xs:」开头，镜头内描述照旧连续叙述、硬切 分隔，各镜时长（整数秒）相加等于总时长。

阶段三 — 成品交付
- 输出一个可直接复制的最终提示词纯文本代码块。
- 代码块内部按以下顺序组织：
  1. 风格锁定
  2. 素材锚定
  3. 连续叙述正文（含人物表演描述）
- 成品交付末尾必须提示：
  @中文名 / @道具名 对接平台素材库时对应到库中素材即可，并人工复核人物衣着、妆发、伤痕、道具状态、场景陈设、光线方向、人物表演基调。

【附录A:表演术语锚定词典】
供画面落地正文快速取用，把抽象情绪转为可见表演。

眼神方向：直视 / 回避 / 偷看 / 下压 / 放空 / 上看 / 侧看
眼神强度：松 / 稳 / 紧 / 锁定 / 闪动
眼皮张力：放松 / 上眼皮微抬 / 下眼睑轻收 / 半垂 / 张开过大
瞳孔状态：放大 / 收紧 / 失焦 / 聚焦
眉部：眉头轻收 / 眉尾下压 / 眉毛上抬 / 单侧眉轻动 / 眉间紧绷 / 眉眼放松
嘴角：轻微上扬 / 压住 / 下压 / 僵住 / 单侧轻动
嘴唇：放松 / 轻抿 / 紧绷 / 微张 / 张开又闭上 / 下唇轻收
下颌：放松 / 轻收 / 绷紧 / 微抬 / 微缩
面部张力：0%(完全放松) / 50%(清晰表达) / 100%(冲突爆发)，默认 30%-60%
呼吸：放松 / 变浅 / 吸气停住 / 轻轻呼气 / 急促
手指：自然放松 / 合拢 / 指向对方 / 抓紧衣角 / 悬停 / 轻敲
手掌：开放 / 收缩 / 贴近身体 / 朝外 / 双手靠脸侧 / 交叠
肩颈：放松 / 微缩 / 抬起 / 下沉 / 颈前伸 / 颈后撤
身体轴线：前倾 / 后仰 / 侧开 / 转向对方 / 身体不转眼神转 / 偏头 / 低头 / 抬头
下肢：稳定站姿 / 膝盖微内扣 / 脚尖朝对方 / 脚尖偏离 / 脚步停住 / 轻轻后撤

常用情绪快速配方（表层+次级+对抗+核心）：
- 小生气：表层生气 + 次级委屈 + 对抗不想服软 + 核心希望被在乎 → 眉头轻压、嘴角下压、眼神直视又移开、身体侧开但脚尖朝对方。
- 嘴硬但在乎：表层装冷淡 + 次级在乎 + 对抗不想承认 + 核心依恋 → 眼神避开但偷瞄、嘴角压住、身体侧开脚尖仍朝对方。
- 委屈忍住：表层委屈 + 次级忍耐 + 对抗不想被看出 + 核心自尊 → 眉尾轻压、眼神发软不直视、嘴唇抿住、肩膀略缩、呼吸变浅。
- 震惊但喜欢：表层惊讶 + 次级喜欢 + 对抗未反应过来 + 核心被吸引 → 眼睛微睁、眉毛轻抬、嘴微张、头先后仰再靠近。
- 克制怒意：表层平静 + 次级愤怒 + 对抗维持体面 + 核心受伤 → 眼神下压锁定、下颌绷紧、嘴唇紧绷、呼吸变浅、手指收紧。
- 害羞心动：表层不好意思 + 次级心动 + 对抗怕太明显 + 核心渴望靠近 → 眼神短暂回避、嘴角压不住上扬、下巴微收、肩膀略内收、手部小动作。
