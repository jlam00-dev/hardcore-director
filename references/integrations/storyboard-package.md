# 分镜交付包与连续性门禁

本模块吸收 Agentara `video-storyboard` 的场次编号、时间核算、素材复用和连续性检查思想，但不把固定九宫格当作默认答案。

## 交付形态

- 默认：每个镜头一张独立图片，加一份镜头表。独立图片更适合后续图生视频、局部返工和素材引用。
- 用户明确要提案板/联系表时：再生成或排版一张总览板。
- 用户明确要求一张多宫格直接作为平台参考时：才使用单张网格，并写清每格作用。
- 分镜画面必须由图像生成模型或用户素材产生；程序化排版只能整理已经生成的画面，不能替代画面创作。

## 文件约定

```text
storyboard/
  scene-01/
    shot-01.png
    shot-02.png
    manifest.md
```

存在同名文件时不覆盖；只有用户明确要求替换时才覆盖，否则使用 `-v2`。

## 每镜字段

| 字段 | 要求 |
| --- | --- |
| 镜号/时间 | 起止时间连续，总和等于场次时长 |
| 叙事功能 | 这一镜让观众知道、感到或期待什么 |
| 构图 | 画幅、景别、机位、主体位置、前中后景 |
| Blocking | 人物站位、朝向、视线、动作方向、距离 |
| 状态变化 | 起始状态 → 可见动作 → 终止状态 |
| 连续性 | 人脸、服装、伤痕、道具、数量、光线、天气、空间地理 |
| 声音 | 对白、环境声、动作声、音乐和声音桥 |
| 生成用途 | 首帧、尾帧、身份参考、动作参考或风格参考 |

## 连续性台账

建立一个只记录可验证事实的台账：

- 人物：脸、发型、体型、服装、鞋、配件、妆容、伤痕；
- 道具：归属、左右手、朝向、开合、损坏、液位、数量；
- 空间：门窗、道路、关键标志、人物相对位置、轴线；
- 环境：时间、天气、主光方向、色温、雾/雨/烟状态；
- 动作：进入方向、退出方向、受力点、落点、镜尾姿势。

后一个镜头必须从前一个镜头的终止状态开始，除非剧本明确发生时空跳转。

## 画面生成前

1. 搜索当前对话和项目内已批准的角色图、产品图、场景图和前序分镜；
2. 有视觉参考就传给图像生成模型，不只依赖文字；
3. 先锁定画幅、人物、文案、风格、视觉锚点和终止状态；
4. 每轮只改一个变量；
5. 文字、标志或 UI 必须准确时，优先留出后期叠加位置，不让图像模型临场拼字。

## 质量门禁

- 每张图对应一个清晰镜头，不用近似重复画面凑数；
- 镜头变化推进动作、信息或视点，同时不破坏连续性；
- 文件数量、画幅、编号和用户要求一致；
- 镜头时长总和精确等于场次时长；
- 角色、服装、道具和空间变化都有剧情依据；
- 输出后逐张检查，而不是只检查总览图；
- 分镜图与提示词中的镜号、动作、时间和素材职责一致。
