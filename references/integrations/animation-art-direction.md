# 动画美术导演

用于原创动画的美术定调、跨场视觉连续性和分镜转提示词。当角色、环境、色彩、材质或动作节拍需要形成同一套规则时，读本模块并填写[一页美术简报](../support/animation-art-brief-template.md)。完整走查见[原创三镜示例](../support/animation-art-direction.example.md)。简单单镜只记录会影响画面的决定。

先从已确认的剧本或简报取故事节拍、受众、画幅、交付规格及已有视觉资产。用 [角色设计](../character-design.md) 和 [场景设计](../ai-scene-design.md) 补齐角色、空间事实。选本模块作美术专项时，只补其余确实缺少的能力，遵守总控的模块装配上限。

## 用一个叙事问题选方法

先写观众在这个场次要辨认什么、何时辨认，再把视觉方向定在两条轴上。空间偏平面图形还是体积光影，表面偏手作痕迹还是数字或混合质感。两轴用于筛选方向，允许同一项目按层分开设计。每个案例只负责一个问题，写清借用的可见做法、适用范围，以及留给原创设计的内容。优先挑能共同工作的少数案例。

| 本项目要解决的问题 | 可观察的做法 | 研究页码 |
| --- | --- | --- |
| 主体缩小后还能辨认 | 给角色一个能单独读出的外形与关键姿势。用剪影检查人物身份和动作方向。 | PDF 第 6–7 页《阿基米德王子历险记》 |
| 角色被高细节场景吞没 | 分开设计轮廓边缘与背景细节密度，再指定前、中、后景哪些随镜头产生视差。 | PDF 第 8–9 页《白雪公主和七个小矮人》 |
| 画面有传统语言但各层不统一 | 从一个构形原则推导角色边形、环境图案和动作姿态，再为本项目重新发明这些形态。 | PDF 第 14–15 页《大闹天宫》 |
| 低运动量镜头仍要有叙事进展 | 给留白定位置，指定哪处墨色或环境变化传递新信息，保留主体动作的停顿。 | PDF 第 22–23 页《山水情》 |
| 进入另一个世界仍能读懂主线 | 贯穿一个角色或道具锚色，让转换前后共享一个画面形状或位置。 | PDF 第 42–43 页《红辣椒》 |
| 动作爆发缺少落点 | 为蓄势、短动作、结果定住三个节拍分配时间，提前说明哪层保持静止。 | PDF 第 32–33 页《武士杰克》 |

研究来源为 Tingyu 编撰的《50部动画的美术设计解析》，2026 年 11 月版。页码按 PDF 物理页计，以上为片例中的画面观察及其方法转译。涉及片源、作者分工或制作史的事实，按原始制作资料另核。包内保留原创方法和模板。项目参考须有清楚的来源、版本和使用范围。原创项目从案例提取形状、色彩、层次或动作原则，再设计自己的轮廓、服饰、标志与道具。片名和作者名留在研究出处，平台提示词写可见特征、动作与素材职责。

## 用三层规则控制变化

1. **全片锁定**。选身份轮廓、核心服装和道具形态、环境轴线、材质边界、反复出现的叙事锚点。每项写成可检查的观察，例如“雨衣帽沿为平弧，左袖只有一条白缝”。能决定景别或遮挡时，补角色线条与背景疏密的关系。记录世界空间里的位置和光向，由当前机位推导画面左右。
2. **分场可变**。沿 `scene_id` 与剧情节拍写允许变化的状态、触发条件和结束状态。区分占画面较多的底色与引导注意力的叙事强调色，分别写对象、出现时机和可见关系。少量亮色承担线索时，即使面积小，也须单列。用[色调工具](../tint-to-prompt.md)细化相对明度、饱和度和色值。截图采样只适合找基底配色。PDF 第 14 页的色板就以较大面积的青灰、绿调为主，图中亮黄衣和红鞋仍须另外识别。
3. **镜级例外**。只有剧情有明确需要时才立例外。按 `shot_id` 写变化项、触发帧或动作、终止帧或状态、下一镜如何承接、哪些身份和空间锚点继续保留。例外涉及已锁条件时，先在上游确认对应的场次规则，再刷新受影响的分镜和提示词。

材质按层写清归属。角色表面、场景表面和全画面效果分别规定纹理密度、边缘清晰度与运动关系，例如纸纹随墙面移动、印刷颗粒固定在画幅上。手绘、剪纸、定格等词需要落到可见结果，制作管线由项目另行确定。

表演先写起势、动作与结果停留，再分配主体、镜头、环境或特效各自的运动窗。动作节拍描述姿势更新的密度。交付 FPS 来自项目时间线。24 FPS 下，局部每两帧更新一次姿势是一种表演节拍，镜头和背景仍可连续运动。模型能否精确实现，按目标平台能力与实片逐镜看验。

## 写回现有交接

按 [创作协作合同](creative-collaboration.md) 沿用 `scene_id`、`shot_id` 和 `beat_ids`。简报是一份视觉决策记录，正式交接继续使用现有字段。

| 决定 | 写到哪里 |
| --- | --- |
| 全片画幅、时间线及可逐镜核对的不变量 | `project.aspect_ratio/fps/total_frames` 和 `project.locked_state`。锁定值在 `direction.shots[].start_state/end_state` 与 `storyboard.board.shots[].start_state/end_state` 保持一致。 |
| 当场发生的变化与本镜例外 | `direction.shots[].blocking`、`performance`、`camera_intent` 及首尾状态。用 `storyboard.board.shots[].start_frame/end_frame` 对齐镜头区间，并在相邻镜的首尾状态写清可见变化。 |
| 真实参考的视觉职责与排除项 | `storyboard.board.shots[].references` 的 `asset_id/role/exclude`。同素材在同镜只承担一个主职责。研究案例保留在简报来源区，真实生产参考用已确认的素材 ID。 |
| 首帧所见与镜内变化 | `prompts.shots[].image_prompt` 写动作起点的构图、形态、色彩与材质。`video_prompt` 写动作顺序、何时保留或改变视觉状态、终态。`reference_asset_ids` 只引用该镜已登记素材。按[模型路由](../prompt-tools/model-router.md)走一个目标适配器。 |

进入[分镜交付](storyboard-package.md)前做一次小样检查。把首帧缩到能看见全片联系表的尺寸，验证主体和关键动作仍可辨认。对照相邻两镜，检查叙事强调色、轮廓、持物、世界空间锚和材质边界是否按规则变化。再用 [分镜机器门禁](storyboard-quality-gates.md)核对时长、镜号、引用与首尾状态。画面可读性、实际渲染的姿势节拍和风格连续性，由人看样片确认。授权沿用项目既有流程。
