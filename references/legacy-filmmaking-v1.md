# 第一章：角色设计

> 来源：`character-design` skill · 白梦客 · v5.0

## 1.1 核心范式转移

| 旧范式 | 新范式 |
|--------|--------|
| 让角色讨人喜欢 | 让角色**令人难忘** |
| 帅哥靓女 | 不完美、有缺陷、有争议 |
| 单一原型 | **原型混搭**（杀手+导师+爱人同一人） |
| 完美主角团 | **群像设计**，每个配角都可能成为爆点 |
| 近似色、和谐配色 | **色彩暴力**（高饱和、极端对比） |
| 固定姿势站桩 | **姿态叙事** |

**当代记忆锚点 = 情感刺痛 + 文化共鸣 + 打脸美学**

---

## 1.2 角色DNA七字诀

设计角色七个维度，全部用"差异性"贯穿：

**一、群像优先**
先设计群像，再提取个体。角色A的"善良"必须由角色B的"邪恶"衬托。
防止AI融合：色块差异、体型差异、服装差异、姿态差异。

**二、原型混搭**
两个原型叠加在同一角色上，差异性翻倍：
```
Hero + Shadow = 被使命撕裂的悲剧英雄
Hero + Mentor = 用死亡教育后辈的牺牲者
Shadow + Ally = 表面敌人实际帮助主角
Mentor + Shadow = 平日是普通老头（老乞丐/火云邪神）
```

**三、姿态叙事**
```
姿态 = 重心位置 × 四肢角度 × 脊椎曲直 × 头部位置
```
- 高重心=自信（直立），低重心=压抑（下沉）
- 四肢张开=开放，紧缩=封闭

**四、情绪-表情-姿态联动**

| 情绪 | 面部 | 姿态 |
|------|------|------|
| 愤怒 | 眉+30°上扬、嘴角下压 | 身体前倾、拳头紧握 |
| 悲伤 | 眉尾上翘、嘴角下弯 | 肩膀内收、身体下沉 |
| 恐惧 | 瞳孔放大、O型嘴 | 身体后退、双臂护胸 |
| 喜悦 | 眼睛弯月形、嘴角上扬 | 身体放松、肩膀抬起 |

**五、色彩暴力**

| 类型 | 手法 | 案例 |
|------|------|------|
| 极端饱和 | 超高饱和度 | 瑞贝卡：绿红配 |
| 极端对比 | 黑白 vs 彩虹 | 星期三：黑白 vs 室友五彩 |
| 色彩隔离 | 环境单色+角色点缀 | 夜之城：深蓝+黄色夹克 |

AI色彩稳定性：纯红/纯黄/霓虹蓝 ★★★★★ > 深红/橙色 ★★★★ > 正蓝/绿 ★★★ > 深灰 ★★ > 肤色/浅灰 ★

**六、服装道具**
- 四大功能：造型/叙事/身份认同/锚定
- 服装即角色符号：麦克斯的红围巾、星期三的黑白

**七、极端对比**
```
1. 外表 vs 真实（普通人外表/绝世高手内心）
2. 色彩 vs 内容（可爱画风/黑暗故事）
3. 姿态 vs 身份（杀手用园艺姿态）
4. 场景 vs 角色（童话世界里的黑暗角色）
```

## 1.3 角色一致性维护（三层锚定）

AI视频逐镜头生成，无记忆。只认：参考图 + 提示词 + 空间约束。

**第一层：参考图锚定（最强）**
标准配置：角色立绘三件套 = 正脸图 + 侧脸图(90°) + 全身站立图

**第二层：DNA标签卡锚定（核心）**
```
【角色名】
- 面部几何：[脸型/颧骨/眉形/眼形/鼻形/嘴形/下巴]
- 体型：[身高/肩宽/体型/重心位置]
- 姿态习惯：[标志性姿态/重心/站姿/坐姿]
- 服装：[主色/辅色/标志性单品]
- 色彩锚点：[主色/辅色/点缀色]
- 标志性细节：[疤/痣/眼镜/配件]
```

**第三层：镜头设计锚定（空间约束）**
每个镜头必须包含：画面位置(左/中/右) + 相机距离 + 空间关系 + 视线方向

**一致性检查清单（每镜必查）**
```
□ 参考图是否为同角色同服装？
□ DNA标签是否完整（面型/体型/服装/色彩/细节）？
□ 镜头设计中角色位置是否与前后镜头一致？
□ 色彩锚点是否出现在提示词中？
□ 标志性细节是否被提及？
□ 光影方向是否影响角色色彩呈现？
```

## 1.4 Blocking视线叙事

**六种站位类型：**

1. **对峙型**（2人）：A左1/3，B右1/3，视线中央交汇，中间留白=张力空间
2. **导师-学生型**：导师右1/3面朝左下，学生左1/3仰望导师，导师比学生高
3. **三角站位型**（3人）：A主导位左，B辅助位右，C后方略高
4. **孤立型**：主角居正中，其他角色在外围，主角=被聚焦/被围攻/独白
5. **包围型**（4人以上）：A左上B右上C左下D右下，E在中央=被包围者
6. **纵深追踪型**：A在前(近景)，B在后(远景)，同一方向站立或行走

**视线是叙事工具：**
- A看B → 观众被引导看B
- A低头/看地 → 内省、压抑、失败
- A仰头/看天 → 希望、祈祷、死亡
- A瞳孔高光消失 → 死亡、精神崩溃

# 第二章：场景设计

> 来源：`ai-scene-design` skill

## 2.1 核心理念：场景 = 世界观的物理容器

场景设计终极目标不是"好看"，而是让场景本身成为叙事工具：
1. **叙事锚点**：场景名 = @标签 = AI生成的稳定参考点
2. **情绪容器**：光影/构图/色调直接决定观众情绪
3. **IP宇宙入口**：好的场景观众会拿去做二创

## 2.2 场景设计三层分析

```
叙事需求
    ↓
第一层：这个场景要完成什么叙事任务？
    ↓
第二层：完成这个任务需要什么空间特性？
    ↓
第三层：这些特性如何转化为视觉语言？
```

**叙事任务分类：**

| 叙事任务 | 本质问题 | 例子 |
|---------|---------|------|
| 建立世界观 | 这个世界是什么样的？ | 展示外星城市 |
| 揭示角色 | 这是一个什么样的人？ | 展示角色住所 |
| 建立关系 | 角色之间是什么关系？ | 两人在什么空间对话 |
| 制造张力 | 故事在积累什么？ | 暴风雨前的平静 |
| 释放情绪 | 观众应该感受到什么？ | 孤独、温暖、压迫 |
| 转折标记 | 故事发生了什么变化？ | 同一个房间但变了 |

## 2.3 场景描述词结构公式

```
主体环境（地点/空间类型）
+ 时间/天气（决定自然光色温）
+ 空间逻辑（人物动线/机位可能性）
+ 光影参数（主光类型 + 介质 + 光比）
+ 氛围关键词（情绪方向）
+ 风格标签（画风/导演风格参考）
```

**场景设计三原则：**
1. **空间逻辑**：布局需符合人物动线和摄影机位
2. **时代/世界观特征**：装饰、建筑风格准确反映背景
3. **光影优先**：光照设计需考虑时间、天气、情绪

## 2.4 光影 × 情绪

| 光影类型 | 情绪效果 | 适合叙事 |
|---------|---------|---------|
| 硬光+顶光 | 审讯、压迫 | 恐惧、紧张 |
| 柔光+侧面 | 回忆、温柔 | nostalgia |
| 背光+轮廓 | 孤独、神秘 | 分离 |
| 局部光（单点） | 聚焦、孤立 | 黑暗中的唯一亮 |
| 无光（纯黑） | 恐惧、未知 | 虚无 |
| 冷光（蓝） | 冷漠、疏离 | 孤独 |
| 暖光 | 温暖、亲密 | 安全 |

# 第三章：导演视角顾问

## 3.1 胡金铨 · 武侠禅意

> 「武侠不是"打"，是"动"，动是禅。」

**TL;DR**：`大地色+苍青+侧逆光+烟雾+长镜头凝视`

**六核心心智模型：**

1. **动即是静**：武侠不是"打"，是"动"。剪辑点不在动作爆发，在张力对峙。
2. **省略即力量**：不展示过程，只展示结果——省略的部分由观众想象填充。
3. **自然是角色**：自然不是背景，是心境的外化。竹林是修炼场，是禅境。
4. **静→动→静节奏**：对峙(长)→爆发(短)→沉淀(长)。动作只是"呼吸"之间的短暂停顿。
5. **天人合一**：武术=禅修，对决=悟道，暴力=仪式。
6. **武侠作为哲学**：武侠是艺术类型，不是娱乐类型。

**决策启发式：**
- 剪辑点在张力，不在动作
- 声音只在必要时出现
- 等光，不造光（大量外景，晨雾/黄昏）
- 前景遮挡60%+创造层次
- 动之后必留静
- 自然光为主，晨雾黄昏最优

**表达DNA：**
- 句式：短句为主，静谧留白
- 高频词：静、空、禅、意、气、留白、省略
- 禁忌词：打、杀、爆、爽、燃
- 视觉优先：台词第二，画面第一

**触发词**：「胡金铨视角」「武侠美学」「禅意」「动即是静」「静→动→静」「省略即力量」

## 3.2 王家卫 · 都市孤独

> 「时间是我电影的核心，所有的故事都是关于'时间'——时间过去，爱消失，记忆留下。」

**TL;DR**：`霓虹+琥珀+低照度+手持晃动+抽帧慢动作`

**六核心心智模型：**

1. **时间是艺术**：时间是线性的，但记忆是碎片的。用抽帧/慢动作打乱时间。
2. **记忆作为真实**：记忆比现实更真实，过去比现在更重要。
3. **过曝=记忆**：过曝镜头=记忆闪回，不是技术失误。
4. **物件是时间标记**：凤梨罐头、船票、过期的沙丁鱼——物件标记时间的流逝。
5. **错过叙事**：故事的核心永远是"差一点"和"来不及"。
6. **抽帧的慢**：抽帧慢动作不是浪漫，是时间被拉长的痛苦。

**色彩配方**：高饱和撞色（琥珀/红/蓝/霓虹）+ 低照度 + 局部过曝
**构图**：手持晃动 + 深焦 + 框架构图（门框/窗框/镜子）

**触发词**：「王家卫视角」「都市疏离」「霓虹」「抽帧」「时间与记忆」「错过叙事」「物件作为时间标记」

## 3.3 北野武 · 暴力沉默

> 「我想拍的是'暴力之后'——不是暴力本身。暴力之后是什么？是沉默。」

**TL;DR**：`冷蓝+高对比+极简留白+长镜头静止+低反差`

**六核心心智模型：**

1. **暴力→沉默**：暴力之后是沉默，沉默比暴力更重。
2. **极简留白**：负空间60%+，画面极度克制。
3. **静→爆节奏**：长时间的沉默蓄力，爆发只在瞬间。
4. **无意义美学**：暴力是无意义的，不是英雄主义，不是正义伸张。
5. **都市孤独**：雨夜东京、雪景海岸——都市空间里的人永远是孤独的。
6. **漫才节奏**：暴力与喜剧并置，冷幽默是存在的解药。

**色彩配方**：北野武蓝灰（影#0A1420/光#E8E8E8）+ 冷调 + 低反差
**构图**：固定镜头 + 长镜头凝视 + 极简场景

**触发词**：「北野武视角」「暴力沉默」「蓝灰」「冷峻」「静→动→静」「暴力循环」「mono no aware」

## 3.4 塔可夫斯基 · 雕刻时光

> 「电影不是用来讲述故事的艺术，而是用来雕刻时光的艺术。」

**TL;DR**：`自然元素（水/雨/火/风）+ 长镜头凝视 + 超慢节奏 + 诗意现实`

**六核心心智模型：**

1. **时间作为物质**：电影是时间雕刻，不是故事讲述。观众感受的是时间流逝本身。
2. **存在的电影**：拍人的存在状态，不拍事件发生。
3. **自然元素语言**：雨/水/火/风不只是背景，是有意义的符号。
4. **长镜头凝视**：拒绝剪辑，让观众沉浸于时间的绵延。
5. **诗的逻辑**：情绪/意象的联结，而非因果链条。
6. **空气**：画面里的空气感、湿度、温度——让空间有呼吸。

**声音设计**：沉默是常态，声音强化孤独感
**光线**：自然光为主，晨雾/雨/烛光

**触发词**：「塔可夫斯基视角」「雕刻时光」「长镜头凝视」「潜行者」「乡愁」「雨/水/火/风」

## 3.5 宫崎骏 · 动画诗意

> 「我相信这个不完美的世界，我相信孩子们的眼睛。」

**TL;DR**：`手绘质感+自然主义+成长有代价+飞行母题+生态批判`

**六核心心智模型：**

1. **自然是活的**：自然不是背景板，是有意志的存在，与人类共生/对立。
2. **手绘的呼吸**：手绘的不完美=生命感，数字动画永远缺少那一层。
3. **成长穿越丧失**：所有故事的核心是失去——但失去之后仍然值得活着。
4. **飞行母题**：飞行=自由=反抗=灵魂的释放。
5. **生态批判**：工业文明 vs 自然秩序，张力来自人类对自然的侵占。
6. **少女成长**：最纯净的视角，最直接的勇气，最深刻的失去。

**色彩配方**：高饱和 + 暖色为主 + 自然渐变 + 空气感
**视觉特征**：蓝天白云、植被丰茂、飞行场面

**触发词**：「宫崎骏视角」「吉卜力」「自然主义」「手绘动画」「飞行母题」「少女成长」

## 3.6 李安 · 跨文化张力

> 「我拍的是两种文化的夹缝中人。」

**TL;DR**：`东方克制+西方心理+第三空间+情感压抑+家庭战场`

**六核心心智模型：**

1. **第三空间**：两种文化之间的夹缝，是最有创造力的地方，也是最痛苦的。
2. **情感压抑**：东方文化的压抑感，通过身体/动作/沉默外化。
3. **家庭战场**：家庭是权力的战场，饭桌是东方文化的权力核心场。
4. **身体作为战场**：身体承载文化冲突，武功/动作是内在精神的外化。
5. **文化对话**：不是谁胜谁负，而是两种文化如何在对方身上留下痕迹。
6. **压抑→爆发→余韵**：情绪曲线永远是从压抑开始，以爆发释放，留有余韵。

**触发词**：「李安视角」「跨文化」「情感压抑」「第三空间」「卧虎藏龙」「断背山」「家庭战场」

# 第四章：AI视频提示词

> 来源：`video-prompt-writer` + `style-fusion` skills

## 4.1 核心理念

> 视频模型是"视觉序列匹配器"。它理解画面A→画面B→画面C的变化，不理解因果逻辑和情绪标签。
> 提示词要写成它能匹配的"视觉序列描述"。

## 4.2 提示词结构公式

```
【导演开场白】→【全局空间锚点卡】→【多参挂载】→【镜头单元】
```

**镜头Prompt标准模板：**
```
[场景描述]，
[角色名]在[画面位置]，
[角色DNA：面型/服装/色彩锚点/细节]，
[姿态]，[表情]，
[角色看向哪里]，
[光源方向]，
[景别]，
[画面比例]
```

**群像Prompt模板：**
```
[场景描述]，
[角色A名]在[位置]，[角色A的DNA/姿态/表情/视线方向]，
[角色B名]在[位置]，[角色B的DNA/姿态/表情/视线方向]，
[角色间空间关系]，
[光源方向]，[景别]
```

## 4.3 风格融合矩阵（B×A）

**B系列（内容风格）：**
| 代码 | 风格 |
|------|------|
| B1 | 超现实 + 生物形态 |
| B2 | 赛博朋克 + 故障艺术 |
| B3 | 梦核 + 蒸汽波 |
| B4 | 极简 + 装饰艺术 |
| B5 | 怪核 + 童心 |

**A系列（导演风格）：**
| 代码 | 风格 |
|------|------|
| A1 | 胡金铨 × Hollywood Golden Age |
| A2 | 王家卫 × French New Wave |
| A3 | 北野武 × German Expressionism |
| A4 | 李安 × Western Modernism |

**融合示例**（B2×A3 = 赛博+北野武）：

# 第六章：节奏剪辑

> 来源：`rhythm-to-prompt` skill

## 6.1 三种基本剪辑节奏

| 类型 | 镜头时长 | 适用场景 | 情绪特征 |
|------|---------|---------|---------|
| **快剪** | 1-3秒/镜 | 追逐/动作/紧张升级 | 高张力、肾上腺素 |
| **正常剪** | 3-8秒/镜 | 叙事/对话/情感 | 自然流畅、叙事清晰 |
| **慢剪** | 8秒+/镜 | 情绪/留白/仪式 | 凝视、内省、诗意 |

## 6.2 情绪节奏曲线

```
蓄力型(先慢后快)：[0-30%]平稳 → [30-60%]微变 → [60-90%]加速 → [90-100%]爆发
爆发型(先静后惊)：[0-20%]沉默 → [20-40%]暗涌 → [40-70%]骤变 → [70-100%]释放
消退型(渐行渐远)：[0-30%]高潮 → [30-70%]缓降 → [70-100%]余韵
```

## 6.3 分镜衔接类型

| 衔接 | 适用场景 | 视觉特征 |
|------|---------|---------|
| **硬切** | 情绪突变 | 无过渡，直接跳切 |
| **叠化** | 情绪延续、时间流逝 | 淡入淡出，模糊过渡 |
| **续接** | 同一动作的连续 | 上一镜结尾=下一镜开头 |
| **跳切** | 时间压缩、回忆、强调 | 同场景同镜头突然剪 |
| **匹配切** | 动作呼应、视觉对仗 | 方向/形状/运动匹配 |

# 第七章：声音与音乐

> 来源：`sound-design-to-prompt` + `ai-music-generator` skills

## 7.1 声音设计三层

**第一层：Foley（音效）**
真实的物理声——脚步、门关、布料摩擦。每种材质有独特音色。

**第二层：Ambient（环境音）**
空间的声音指纹——餐厅的嘈杂、深夜街道的寂静、森林的风声。

**第三层：情绪音**
强化情绪的声音符号——心悸声、雨声计时、时钟滴答。

## 7.2 AI音乐生成

**BGM生成参数：**
```
风格 / 情绪 / 时长 / BPM / 乐器配置 / 动态曲线
```

**适配平台：** Suno / Seedance Audio / Udio

**场景音乐公式：**
- 悬疑：低BPM + 弦乐 + 不协和音 + 留白
- 温情：中等BPM + 钢琴/吉他 + 暖饱和和声
- 史诗：BPM递增 + 管弦乐 + 动态爆发
- 武侠：民族乐器 + 散板 + 长气息 + 自然环境音叠加

# 第十章：文本人性化

> 来源：`humanizer-zh` skill

## 去除AI写作痕迹五原则

1. **删除填充短语**：去除开场白和拐杖词（"当然""值得注意的是"）
2. **打破公式结构**：避免二元对比、戏剧性分段、修辞性设置
3. **变化节奏**：混合句子长度，两项优于三项
4. **信任读者**：直接陈述事实，跳过软化和辩解
5. **删除金句**：如果听起来像可引用的语句，重写它

**AI写作特征自检：**
- [ ] 夸大的象征意义
- [ ] 宣传性语言
- [ ] 以-ing结尾的肤浅分析
- [ ] 模糊的归因（"研究表明""专家称"）
- [ ] 破折号过度使用
- [ ] 三段式法则（论点-例证-结论）
- [ ] 否定式排比
- [ ] 过多的连接性短语
