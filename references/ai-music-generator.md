# 影视 AI 配乐适配器

本模块只负责把导演意图变成可生成、可剪辑、可验收的音乐任务。默认交付提示词、结构表和混音要求；没有用户明确授权时，不登录平台、不上传素材、不调用付费生成。

当前适配依据为 `bitwize-music-studio/claude-ai-music-skills` 的 Suno V5/V5.5 提示词、分轨与母带思路。上游已从旧版单文件扩展为完整音乐制作插件，本包只吸收与视频配乐直接相关的部分，不复制其工程、代理或全部曲风资料。

## 先建立画面音乐点位

不要先选曲风。先从剧本、分镜或粗剪中提取：

| 字段 | 要求 |
| --- | --- |
| 总时长 | 成片时长、音乐需要覆盖的区间、是否允许尾部延长 |
| 叙事功能 | 建立氛围、推进、制造悬念、反转、释放或 CTA |
| 关键点 | 入点、转折、高潮、停顿、对白窗口、出点 |
| 动态曲线 | 每一段的能量等级与升降方向 |
| 前景关系 | 音乐、对白、旁白、环境音谁是当前前景 |
| 交付形式 | 完整混音、纯伴奏、分轨、循环版或短切版 |

对白和旁白密集处先给空间，不用更响、更满的音乐补叙事问题。

## 选择生成模式

- 影视配乐、广告 BGM、氛围床：默认无歌词、纯器乐。
- 主题歌或画内演唱：单独写人声身份、音域、语言和演唱动作。
- 精确卡点：先生成略长版本，再在后期按点位裁切；不要承诺生成模型精确命中每个剪辑帧。
- 循环音乐：同时定义可循环的节奏纹理与允许人工修剪的循环点。

## Suno V5/V5.5 提示词结构

风格框使用三段式：

```text
[人声身份与演唱方式，仅人声曲需要]。
[主类型 + 最多两个子类型 + BPM + 2–3 件关键乐器]。
[制作质感 + 动态走向 + 画面功能]。
```

规则：

- 有人声时把人声描述放在最前；纯器乐省略人声段。
- 每个描述词承担不同信息，删除同义词堆叠。
- 不写真实艺人或乐队名字，改写成可听见的音色、演唱、编配和制作特征。
- 需要排除时只列 2–4 项，例如 `no choir`、`no electric guitar`；排除项只改变概率，不是绝对保证。
- 不把时长当成精确参数。主要通过段落数量、段落长度、`[Outro]` 与 `[End]` 控制，再由后期对齐成片。

歌词框只能放真正要唱出的歌词和合法段落标签，不能放括号里的舞台说明。纯器乐可使用：

```text
[Intro - restrained]

[Main Theme - gradual lift]

[Bridge - tension release]

[Outro - sparse]

[End]
```

每个段落标签可带简短表演提示；同一段最多三个提示，避免让结构标签变成形容词仓库。

## 通用平台提示词

当平台不是 Suno，使用中性结构：

```text
用途：[镜头或段落功能]
时长：[目标长度与允许余量]
类型：[主类型 / 子类型]
速度与拍号：[BPM / 拍号]
编制：[2–5 个关键声部]
动态：[起点 → 转折 → 高潮 → 终点]
声音质感：[空间、颗粒、干湿、远近]
对白窗口：[时间段与需要让出的频段/密度]
排除项：[2–4 个真正会破坏画面的元素]
```

平台没有公开固定字段时，把这些标题标为“本 Skill 制作模板”，不要冒充官方语法。

## 混音与母带门禁

- 必须实际测量综合响度和 True Peak，不能把提示词中的目标当成检测结果。
- 没有平台交付规范时，`-14 LUFS`、`-1 dBTP` 只能作为流媒体工作起点，不是所有广告、电影或平台的统一标准。
- 旁白为主时先做音乐闪避或自动压低，再判断是否需要整体降响度。
- 需要后期处理时优先请求 WAV；正式母带尽量使用无损源。
- 分轨交付至少标明 drums、bass、harmonic、melodic、vocal/lead、FX 与 master；不存在的声部不要伪造。
- 检查开头和结尾、循环点、突然截断、泵动、削波、相位、底噪以及人声遮蔽。

## 生成后复核

1. 风格与画面时代、空间和人物身份一致。
2. 音乐转折发生在叙事转折附近，而不是只按固定八小节推进。
3. 对白窗口没有被主旋律、强鼓点或人声抢占。
4. 高潮前有足够动态余量，不能从第一秒就满编制。
5. 实际文件的时长、格式、采样率、响度和峰值已测量。
6. 用户只授权了提示词时，到此停止；只有明确授权后才进入具体平台生成。
