# 动画美术一页简报

用于[动画美术导演](../integrations/animation-art-direction.md)到导演、分镜与提示词的交接。短任务保留直接影响画面的行。填写现有项目和素材 ID，规格沿用项目主表。可参考[原创三镜示例](animation-art-direction.example.md)。

**项目与叙事任务** `项目 ID / 剧本修订 / 适用场次` · 观众要在什么节拍看见什么？

**交付规格** `画幅 / 项目 FPS / 总帧数` · 以已确认的 `project` 为准。

**视觉方向** `偏平面或体积`、`偏手作或数字混合` · 各写一条能在画面上辨认的做法。

| 层级 | 填写内容 |
| --- | --- |
| 全片锁定 | 身份轮廓与一个辨识特征 `___` · 角色和背景的边缘、疏密与前中后层关系 `___` · 世界空间、主光或关键道具锚 `___` · 固定的材质层与纹理归属 `___` |
| 分场可变 | `scene_id / beat_id` `___` · 底色与明度关系 `___` · 叙事强调色、对象和出现时刻 `___` · 变化触发与结束状态 `___` |
| 镜级例外 | `shot_id / 生效窗口` `___` · 剧情原因和变化项 `___` · 继续保留的锚点 `___` · 收束或恢复的状态、交给哪一镜 `___` |

**动作节拍** `shot_id` · 起势 `___` → 主要动作 `___` → 结果停留 `___`。写清主体、机位和环境各自何时动或停。姿势保持、局部重复等节拍单独记录，交付 FPS 沿用项目规格。

**案例分工** `来源 / 研究页码 / 单一职责 / 借用原则 / 本项目原创替换`。每条只写一个要解决的画面问题。

**生产参考** `asset_id / 版本 / 单一 role / exclude / 待制作或已核可`。同一素材的职责按镜号标记，已核可素材再进入分镜引用。

**首帧与视频** `shot_id` · 起点可见状态 `___` · 动作顺序和变化时点 `___` · 终态及下一镜接续 `___`。

**验收** 缩小后能辨认的主体或动作 `___` · 相邻镜需连续的画面证据 `___` · 需要实际样片验证的节拍或材质 `___`。

写回 `project.locked_state` 的固定值同步到导演和分镜的首尾状态。分场变化、表演和镜级例外交给 `direction.shots` 与 `storyboard.board.shots`。素材的 `asset_id/role/exclude` 交给分镜 `references`。起点与变化分别写入 `image_prompt` 和 `video_prompt`，并沿用该镜 `reference_asset_ids`。需机器交接时按[创作协作合同](../integrations/creative-collaboration.md)填写现有 JSON。
