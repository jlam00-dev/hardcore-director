# 抖音短视频脚本生成器

## 触发条件

当用户需要创作抖音视频脚本、短视频文案、或口播内容时激活。

## 平台特性

- **时长限制**：15秒-10分钟，黄金时长60秒-3分钟
- **用户行为**：快速滑动，前3秒决定去留
- **算法逻辑**：完播率 > 互动率 > 转发率

## 爆款结构

### 黄金3秒开头

**类型A：悬念开头**
```
"你知道为什么90%的人都做错了吗？"
"这个方法，我后悔没早点知道"
```

**类型B：利益开头**
```
"学会这招，每月多赚3000"
"3分钟学会，省下2000块"
```

**类型C：反常识开头**
```
"千万别这样做！"
"原来我们一直都错了"
```

**类型D：共鸣开头**
```
"有没有人和我一样..."
"打工人都懂的痛"
```

## 脚本结构

### 60秒脚本模板
```
【0-3秒】Hook - 抓住注意力
【3-15秒】痛点 - 引发共鸣
【15-45秒】干货 - 核心内容
【45-55秒】总结 - 强化记忆
【55-60秒】互动 - 引导行动
```

### 3分钟脚本模板
```
【0-5秒】Hook - 强力开头
【5-30秒】背景 - 问题铺垫
【30-120秒】正文 - 分点讲解
【120-150秒】案例 - 实际演示
【150-170秒】总结 - 核心回顾
【170-180秒】互动 - 引导关注
```

## 内容类型模板

### 知识口播
```
【Hook】"这个技巧，99%的人都不知道"

【痛点】你是不是也遇到过[问题]？
每次都[痛苦场景]，特别烦

【干货】今天教你3招，彻底解决

第一招：[方法]
第二招：[方法]
第三招：[方法]

【结尾】学会了吗？点赞收藏，下次用得上
```

### 产品种草
```
【Hook】"这个东西，我已经回购5次了"

【展示】看看这个[产品]
[展示产品特点]

【体验】用起来的感觉就是[描述]
[使用演示]

【对比】之前用的[对比产品]
[对比效果]

【结尾】链接在购物车，需要的自取
```

### 剧情类
```
【场景设定】[时间地点人物]

【冲突引入】[矛盾点]

【剧情发展】[情节推进]

【高潮反转】[意外转折]

【结局】[结果]

【点题】[主题升华]
```

## 注意事项

1. **语速控制**：每分钟200-250字
2. **口语化**：避免书面语，像聊天一样
3. **节奏感**：重点处放慢，过渡处加快
4. **情绪饱满**：表情和语气要到位
5. **合规性**：避免违禁词和敏感内容
